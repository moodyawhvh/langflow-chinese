_flow_(流程)是应用工作流的功能化表达。
flow 接收输入、处理数据、产出结果。

flow 由 _components_(组件)构成,每个组件代表应用工作流中的一个步骤。

![工作区中的基础 Prompting flow](/img/workspace-basic-prompting.png)

Langflow 的 flow 完全可序列化,可以保存到 Langflow 安装所在的文件系统,也可以从中加载。

:::tip
想在几分钟内试着构建并运行一个 flow,请参见 [Langflow 快速入门](/get-started-quickstart)。
:::

## 创建 flow

在 [**Projects** 页面](#projects)中,有四种创建 flow 的方式:

* **创建空白 flow**:选择一个项目,点击 **New Flow**,然后点击 **Blank Flow**。

* **从模板创建 flow**:选择一个项目,点击 **New Flow**,然后点击想用的模板。

    <details>
    <summary>什么是模板?</summary>

    模板是预构建的 flow,可以作为你自己 flow 的起点。
    从只有几个组件的基础 flow,到包含大量组件和子 flow 的复杂流程都有。

    例如,**Basic Prompting** 模板演示了一个小型 flow:把聊天输入和预定义指令(作为提示词)一起传给 LLM。
    而 **Vector Store RAG** 模板由两个子 flow 组成,演示如何构建检索增强生成(RAG)聊天机器人:一个子 flow 向向量库写入上下文相关数据和嵌入,另一个子 flow 从向量库查询相似数据来回答用户问题。

    你也可以向 Langflow 代码库[贡献模板](/contributing-templates)。

    </details>

* **复制已有 flow**:找到要复制的 flow,点击 <Icon name="Ellipsis" aria-hidden="true" /> **More**,然后选择 **Duplicate**。

* **导入 flow**:参见[导入与导出 flow](/concepts-flows-import)。

你也可以通过 [Langflow API](/api-flows) 创建 flow,但在熟悉 flow 创建之前,Langflow 团队建议使用[可视化编辑器](/concepts-overview)。

### 添加组件

flow 由[组件](/concepts-components)组成,组件是你在[工作区](/concepts-overview#workspace)中配置并连接的节点。
每个组件执行一项具体任务,例如提供 AI 模型服务或连接数据源。

从 <Icon name="Component" aria-hidden="true" /> **Core components** 和 <Icon name="Blocks" aria-hidden="true" /> **Bundles** 菜单中拖拽组件,加入你的 flow。
然后配置组件设置,并把组件相互连接。

![Chat Input 和 Output 连接到一个 Language Model 组件](/img/connect-component.png)

每个组件都有自己的配置项和选项。其中一些是所有组件共有的,一些则是特定组件独有的。

要构成一个完整的 flow,你需要通过 _连线(edge)_ 或 _端口(port)_ 连接组件,它们接收或发送特定的数据类型。
例如,消息端口在组件之间传递文本字符串。

关于组件配置的更多信息(包括端口类型和组件底层代码),参见[组件概览](/concepts-components)。

### 运行 flow

构建好原型 flow 后,可以先在 [**Playground**](/concepts-playground) 中测试。
准备用 Langflow 做应用开发时,学习如何[用 Langflow API 触发 flow](/concepts-publish),探索[自定义依赖](/install-custom-dependencies)等更高级的配置选项,最终[容器化你的 Langflow 应用](/develop-application)。

准备好上生产环境、或部署可通过公网访问的 Langflow MCP 服务器时,参见 [Langflow 部署概览](/deployment-overview)。

#### Flow 图

flow 运行时,Langflow 会根据节点(组件)和连线(连接)构建一个有向无环图(DAG)对象,并对节点排序以确定执行顺序。

图构建过程会调用每个组件的 `def_build` 函数来验证并准备节点。
随后按依赖顺序处理该图。
每个节点依次构建和执行,已构建节点的结果会传给依赖该结果的下游节点。

## 在项目中管理 flow {#projects}

启动 Langflow 后首先到达的就是 **Projects** 页面。
在这里可以管理 flow 以及各项目的 [MCP 服务器](/mcp-server)。

Langflow 项目类似于文件夹,用于组织相关的 flow。
默认项目是 **Starter Project**,除非你另建项目,否则 flow 都存放在这里。
点击 <Icon name="Plus" aria-hidden="true"/> **Create new project** 即可创建项目。

![Projects 页面中一个项目内的多个 flow](/img/my-projects.png)

:::tip
编辑 flow 后想回到 **Projects** 页面,点击 Langflow 顶栏中的项目名称或 Langflow 图标即可。
:::

### 编辑 flow 详情

1. 在 **Projects** 页面找到要编辑的 flow。
2. 点击 <Icon name="Ellipsis" aria-hidden="true" /> **More**,然后选择 **Edit details**。
3. 修改 **Name** 和 **Description**,然后点击 **Save**。

### 保存与恢复 flow 版本

你可以在 flow 编辑器的 <Icon name="History" aria-hidden="true" /> **Version History** 菜单中保存 flow 版本。

1. 打开想要做版本的 flow。
2. 在 flow 编辑器侧边栏,点击 <Icon name="History" aria-hidden="true" /> **Version History**。
3. 在 **Current** 下点击 **Save**,把 flow 当前状态保存为一个版本。
4. 选择一个已保存的版本,以只读模式预览该 flow。
5. 点击 **Restore**,用所选版本替换当前草稿。

在已保存版本的 <Icon name="EllipsesVertical" aria-hidden="true" /> 菜单中,你还可以 **Export** 或 **Delete** 该版本。

保存的 flow 版本存储在你为 Langflow 部署配置的数据库中。

恢复已保存版本时,如果 **Save current draft before restoring** 处于启用状态,Langflow 会在所选版本覆盖当前工作前先做一份备份。

[flow 自动保存](/environment-variables#visual-editor-and-playground-behavior)与 flow 版本的用途不同。
自动保存在后台保持当前 flow 草稿最新,但不会创建版本条目。
保存的_版本_是你显式创建的快照,用作还原点。

预览已保存版本时,Langflow 会暂时暂停自动保存,避免预览覆盖你的当前草稿。

### 锁定 flow

要防止 flow 被修改,可以将其锁定:

1. 在 **Projects** 页面找到要锁定的 flow。
2. 点击 <Icon name="Ellipsis" aria-hidden="true" /> **More**,然后选择 **Edit details**。
3. 启用 **Lock Flow**,然后点击 **Save**。

重复上述步骤并关闭 **Lock Flow** 即可解锁。

编辑 flow 时,**Lock Status** 显示 flow 当前是 <Icon name="Lock" aria-hidden="true" /> **Locked** 还是 <Icon name="LockOpen" aria-hidden="true" /> **Unlocked**。
编辑 flow 的过程中无法更改锁定状态。

### 移动 flow

把 flow 从一个项目移动到另一个项目:

1. 在 **Projects** 页面找到要移动的 flow。
2. 把 flow 从 flow 列表拖到项目列表中的目标项目名称上。

### 删除 flow

1. 在 **Projects** 页面找到要删除的 flow。
2. 点击 <Icon name="Ellipsis" aria-hidden="true" /> **More**,然后选择 **Delete**。

## Flow 存储与日志

默认情况下,flow 和 flow 执行数据存储在 Langflow 数据库中,flow 日志与其他 Langflow 日志一起存放在 Langflow 配置目录。
更多信息参见[内存管理选项](/memory)和[日志](/logging)。
