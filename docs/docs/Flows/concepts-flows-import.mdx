你可以导出 flow,以便在 Langflow 实例之间迁移、分享给他人或创建备份。

## 导出 Flow

导出 flow 有三种方式:

* **从 Projects 页面导出**:在 [**Projects** 页面](/concepts-flows#projects)找到要导出的 flow,点击 <Icon name="Ellipsis" aria-hidden="true" /> **More**,然后选择 **Export**。要导出一个项目内的所有 flow,点击 **Projects** 列表上的 <Icon name="Ellipsis" aria-hidden="true" /> **Options**,然后选择 **Download**。

* **通过 Share 菜单导出**:编辑 flow 时,点击 **Share**,然后点击 **Export**。

* **通过 Langflow API 导出**:导出单个 flow,使用 [`/flows/download`](/api-flows#export-flows) 端点。
  导出项目内所有 flow,使用 [`/projects/download`](/api-projects#export-a-project) 端点。

导出的 flow 会以 `FLOW_NAME.json` 命名的 JSON 文件下载到本地。
如果导出整个项目,JSON 文件会打包为 zip 压缩包。
更多信息参见 [Langflow JSON 文件内容](#langflow-json-file-contents)。

### Save with my API keys

从 **Projects** 页面或 **Share** 菜单导出时,可以勾选 **Save with my API keys**,导出 flow _以及_已定义的 API key 变量。
无论是否勾选该项,非 API key 变量都会包含在导出文件中。

:::warning
如果你是把 API key 的字面值直接填进组件的 API key 字段,那么 **Save with my API keys** 导出的就是 key 的明文值。

如果 key 存在 Langflow 全局变量中,**Save with my API keys** 只会导出变量名。
:::

当你或其他用户把该 flow 导入另一个 Langflow 实例时,该实例必须存在同名且取值有效的 Langflow 全局变量,flow 才能成功运行。
如有变量缺失或无效,导入 flow 后必须创建或修改这些变量。

## 导入 Flow

可以通过以下方式从本地导入 Langflow JSON 文件:

* **导入到 Projects**:在 **Projects** 页面,点击 <Icon name="Upload" aria-hidden="true"/> **Upload a flow**,然后选择要导入的 Langflow JSON 文件。
* **任意页面导入**:把 Langflow JSON 文件从文件管理器拖拽到 Langflow 窗口中,即可从任意 Langflow 页面导入 flow。
* **通过 Langflow API 导入**:导入单个 Langflow JSON 文件,使用 [`/flows/upload/`](/api-flows#import-flows) 端点。
  导入包含多个 Langflow JSON 文件的 zip 压缩包,使用 [`/projects/upload`](/api-projects#import-a-project) 端点。

### 运行导入的 Flow

导入完成后,flow 即可使用。
如果 flow 中引用了全局变量,请确保你的 Langflow 实例中存在同名且取值有效的全局变量。
更多信息参见 [Save with my API keys](/concepts-flows-import#save-with-my-api-keys)。

## Langflow JSON 文件内容

导出的 flow 会以 `FLOW_NAME.json` 命名的 JSON 文件下载到本地。

Langflow JSON 文件包含:

* 描述 flow 中组件与连接的[节点(Nodes)](#nodes)和[连线(Edges)](#edges)。
* 描述 flow 及其所属项目的[附加元数据](#additional-metadata-and-project-information)。

查看示例 Langflow JSON 文件,可以直接阅读 https://github.com/langflow-ai/langflow/tree/main/src/backend/base/langflow/initial_setup/starter_projects[Langflow 仓库中的模板],也可以在 Langflow 中从模板创建一个 flow、导出,再用文本编辑器打开导出的 JSON 文件。

### 节点(Nodes)

节点代表组成 flow 的组件。
例如,下面这个对象表示一个 **Chat Input** 组件:

```json
{
  "data": {
    "description": "Get chat inputs from the Playground.",
    "display_name": "Chat Input",
    "id": "ChatInput-jFwUm",
    "node": {
      "base_classes": ["Message"],
      "description": "Get chat inputs from the Playground.",
      "display_name": "Chat Input",
      "icon": "MessagesSquare",
      "template": {
        "input_value": {
          "display_name": "Text",
          "info": "Message to be passed as input.",
          "value": "Hello"
        },
        "sender": {
          "value": "User",
          "options": ["Machine", "User"]
        },
        "sender_name": {
          "value": "User"
        },
        "should_store_message": {
          "value": true
        }
      }
    },
    "type": "ChatInput"
  },
  "position": {
    "x": 689.5720422421635,
    "y": 765.155834131403
  }
}
```

每个节点都有形如 `NODE_NAME-UUID` 的唯一标识符,例如 `ChatInput-jFwUm`。

入口节点(如 `ChatInput` 节点)是 flow 运行时最先执行的节点。

### 连线(Edges)

连线代表节点之间的连接。

下面的例子表示 `ChatInput` 节点与 `OpenAIModel` 节点之间的连线(连接):

```json
{
  "className": "",
  "data": {
    "sourceHandle": {
      "dataType": "ChatInput",
      "id": "ChatInput-jFwUm",
      "name": "message",
      "output_types": ["Message"]
    },
    "targetHandle": {
      "fieldName": "input_value",
      "id": "OpenAIModel-OcXkl",
      "inputTypes": ["Message"],
      "type": "str"
    }
  },
  "id": "reactflow__edge-ChatInput-jFwUm{œdataTypeœ:œChatInputœ,œidœ:œChatInput-jFwUmœ,œnameœ:œmessageœ,œoutput_typesœ:[œMessageœ]}-OpenAIModel-OcXkl{œfieldNameœ:œinput_valueœ,œidœ:œOpenAIModel-OcXklœ,œinputTypesœ:[œMessageœ],œtypeœ:œstrœ}",
  "source": "ChatInput-jFwUm",
  "sourceHandle": "{œdataTypeœ: œChatInputœ, œidœ: œChatInput-jFwUmœ, œnameœ: œmessageœ, œoutput_typesœ: [œMessageœ]}",
  "target": "OpenAIModel-OcXkl",
  "targetHandle": "{œfieldNameœ: œinput_valueœ, œidœ: œOpenAIModel-OcXklœ, œinputTypesœ: [œMessageœ], œtypeœ: œstrœ}"
}
```

这条连线表示 `ChatInput` 组件向 `target` 节点(即 `OpenAIModel` 节点)输出 `Message` 类型。
`OpenAIModel` 组件在 `input_value` 字段接收 `Message` 类型。

### 附加元数据与项目信息

flow 的附加信息保存在根级 `data` 对象中:

* 元数据与项目信息,包括 flow 的名称、描述和 `last_tested_version`。例如:

    ```json
    {
      "name": "Basic Prompting",
      "description": "Perform basic prompting with an OpenAI model.",
      "tags": ["chatbots"],
      "id": "1511c230-d446-43a7-bfc3-539e69ce05b8",
      "last_tested_version": "1.0.19.post2",
      "gradient": "2",
      "icon": "Braces"
    }
    ```

* flow 的视觉信息,定义在工作区打开 flow 时视口的位置:

    ```json
    "viewport": {
      "x": -37.61270157375441,
      "y": -155.91266341888854,
      "zoom": 0.7575251406952855
    }
    ```

* <Icon name="StickyNote" aria-hidden="true"/> **Notes(笔记)** 是注释,帮助说明 flow 的用途、配置细节,以及其他对可能编辑该 flow 的用户有用的信息。
  笔记可以包含文本、链接、代码片段等内容。
  以 Markdown 格式编码,并作为 `node` 对象存储。

    ```json
    {
      "id": "undefined-kVLkG",
      "node": {
        "description": "## 📖 README\nPerform basic prompting with an OpenAI model.\n\n#### Quick Start\n- Add your **OpenAI API key** to the **OpenAI Model**\n- Open the **Playground** to chat with your bot.\n..."
      }
    }
    ```
