你可以使用 Langflow 的可视化编辑器来创建、测试和分享 flow,即应用工作流的功能化表达。
flow 由若干组件构成,每个组件代表应用工作流中的一个步骤。

Langflow 的拖拽界面让你无需编写大量代码就能创建复杂的 AI 工作流。
你可以连接不同的资源,包括提示词、大语言模型(LLM)、数据源、代理、MCP 服务器,以及其他工具与集成。

:::tip
想在几分钟内试着构建并运行一个 flow,请参见 [Langflow 快速入门](/get-started-quickstart)。
:::

## 工作区

构建 [flow](/concepts-flows) 时,你主要在工作区中操作。
在这里添加[组件](/concepts-components)、配置组件并把它们连接起来。

![空白的 Langflow 工作区](/img/workspace.png)

在工作区中,你还可以访问 [**Playground**](#playground)、[**Share** 菜单](#share-menu)和 [**Logs**](/logging)。

### 工作区手势与交互

使用以下快捷方式、手势和功能在工作区中导航:

- **水平/垂直平移**:点击并拖动工作区的空白区域。

- **重新排列组件**:在画布上任意拖动组件。

    要改变组件之间的程序化关系,必须操作组件的_连线(edge)_或_端口(port)_。更多信息参见[组件概览](/concepts-components)。

    要启用对齐辅助线,点击 <Icon name="CircleQuestionMark" aria-hidden="true" /> **Help**,然后开启 **Enable smart guides**。

    如果组件都无法编辑,请确认 flow 已[解锁](/concepts-flows#lock-a-flow)。

- **缩放**:在鼠标或触控板上滚动,或点击缩放百分比旁的 <Icon name="ChevronUp" aria-hidden="true" /> **Canvas controls**,查看更多缩放选项:**Zoom In**、**Zoom Out**、**Zoom To 100%** 和 **Zoom To Fit**。

- **添加笔记和评论**:点击 <Icon name="StickyNote" aria-hidden="true"/> **Add Note**。

- **键盘快捷键**:要查看可用快捷键,点击 <Icon name="CircleQuestionMark" aria-hidden="true" /> **Help**,然后选择 **Shortcuts**。

## Playground

如果你的 flow 包含 **Chat Input** 组件,就可以用 **Playground** 运行 flow、与 flow 对话、查看输入输出,并修改 LLM 的记忆来实时调优 flow 的响应。

想亲自试试,可以基于 **Simple Agent** 模板创建一个 flow,然后在工作区编辑 flow 时点击 <Icon name="Play" aria-hidden="true"/> **Playground**。

![Playground](/img/playground.png)

如果 flow 里有 **Agent** 组件,**Playground** 会显示它的工具调用和输出,方便你监控代理的工具使用情况,理解其响应背后的推理过程。

![Playground 中的代理响应](/img/playground-with-agent.png)

更多信息参见[在 Playground 中测试 flow](/concepts-playground)。

## Share {#share-menu}

**Share** 菜单提供以下选项,用于把 flow 集成到外部应用:

* [**API access**](/concepts-publish#api-access):使用自动生成的 Python、JavaScript 和 curl 代码片段,把 flow 集成到你的应用中。
* [**Export**](/concepts-flows-import#export-a-flow):把 flow 导出为 JSON 文件保存到本地。
* [**MCP Server**](/mcp-server):把你的 flow 作为工具提供给兼容 MCP 的客户端。
* [**Embed into site**](/concepts-publish#embedded-chat-widget):把 flow 嵌入 HTML、React 或 Angular 应用。
* [**Shareable Playground**](/concepts-playground#share-a-flows-playground):把你的 **Playground** 界面分享给其他用户。

    这仅用于分享 **Playground** 体验,不适用于在生产应用中运行 flow。

    **Shareable Playground** 在 Langflow Desktop 上不可用。
