Langflow 是一个开源、基于 Python、可深度定制的 AI 应用构建框架。
它支持代理(Agent)、模型上下文协议(MCP)等关键 AI 能力,并且不强制你使用特定的大语言模型(LLM)或向量数据库。

可视化编辑器简化了应用工作流的原型设计,让开发者能快速把想法变成强大且可落地的解决方案。

## 应用开发与原型设计

Langflow 可以帮你开发各类 AI 应用,例如聊天机器人、文档分析系统、内容生成器和智能体应用。

Langflow 内置多个预构建模板,开箱即用,也可按需定制。

### 几分钟创建 Flow

Langflow 的核心用途是创建和提供服务化的 flow,即应用工作流的功能化表达。

[构建 flow](/concepts-flows)时,你需要连接并配置组件节点。每个组件就是工作流中的一个步骤。

借助 Langflow 的[可视化编辑器](/concepts-overview),你可以拖拽组件,快速搭建并测试可运行的 AI 应用工作流。
例如,你可以为电商网站构建一个聊天机器人 flow,利用 LLM 和商品数据存储,让顾客直接询问店铺商品的相关问题。

![Langflow 中的基础 Prompting flow](/img/workspace-basic-prompting.png)

### 实时测试 Flow

你可以使用 [**Playground**](/concepts-playground) 测试 flow,而无需搭建完整的应用栈。
你可以与 flow 交互,实时获得关于 flow 逻辑和响应生成的反馈。

你还可以单独运行某个组件,以隔离方式测试依赖项。

### 运行与服务 Flow

你可以把 flow 当作更正式应用开发的原型,也可以通过 Langflow API 将 flow 嵌入你的应用代码。

如需更深入的开发,你可以把 Langflow 作为依赖构建,或部署一个 Langflow 服务器,通过公共互联网对外提供 flow 服务。

## 无限的修改与集成

Langflow 提供的[组件](/concepts-components)覆盖 AI 应用所需的众多服务、工具与功能。

有些组件是通用的,例如输入、输出和数据存储。
有些则是专用的,例如代理、语言模型和嵌入模型提供商。

所有组件都提供参数,你可以设为固定值或变量值。你还可以使用 tweaks 在运行时临时覆盖 flow 设置。

### 可扩展性

除核心组件外,Langflow 还支持自定义组件。

你可以使用他人开发的自定义组件,也可以开发自己的自定义组件供个人使用,或分享给其他 Langflow 用户。
