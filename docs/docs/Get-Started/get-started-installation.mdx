## 安装并运行 Langflow Desktop {#install-and-run-langflow-desktop}

Langflow Desktop 是 Langflow 的桌面版本,简化了依赖管理和升级。
但部分功能在 Langflow Desktop 上不可用,例如 **Shareable Playground** 和 **语音模式(Voice Mode)**。

<Tabs>
<TabItem value="macos" label="macOS" default>

Langflow Desktop 要求 macOS 13 或更高版本。

1. 访问 [Langflow Desktop](https://www.langflow.org/desktop)。
2. 点击 **Download Langflow**,填写联系信息,然后点击 **Download**。
3. 挂载并安装 Langflow 应用。
4. 安装完成后,打开 Langflow 应用,然后按照[快速入门](/get-started-quickstart)创建你的第一个 flow。

</TabItem>
<TabItem value="Windows" label="Windows">


1. 访问 [Langflow Desktop](https://www.langflow.org/desktop)。
2. 点击 **Download Langflow**,填写联系信息,然后点击 **Download**。
3. 打开**文件资源管理器**,进入**下载**目录。
4. 双击下载的 `.msi` 文件,按照安装向导完成 Langflow Desktop 安装。

    :::tip
    Windows 版 Langflow Desktop 需要系统上可能尚未安装的 C++ 编译器。如果收到 `C++ Build Tools Required!` 报错,请按屏幕提示安装 Microsoft C++ Build Tools,或[安装 Microsoft Visual Studio](https://visualstudio.microsoft.com/downloads/)。
    :::

5. 安装完成后,打开 Langflow 应用,然后按照[快速入门](/get-started-quickstart)创建你的第一个 flow。

</TabItem>
</Tabs>

升级信息请参阅[发行说明](/release-notes)。

在 Langflow Desktop 中管理依赖,请参见[在 Langflow Desktop 中安装自定义依赖](/install-custom-dependencies#langflow-desktop)。

## 使用 Docker 安装并运行 Langflow {#install-and-run-langflow-docker}

你可以使用 Langflow Docker 镜像启动一个 Langflow 容器。
更多信息请参见[在 Docker 上部署 Langflow](/deployment-docker)。

1. 安装并启动 [Docker](https://docs.docker.com/)。

2. 拉取最新的 [Langflow Docker 镜像](https://hub.docker.com/r/langflowai/langflow)并启动:

    ```bash
    docker run -p 7860:7860 \
      -e LANGFLOW_AUTO_LOGIN=false \
      -e LANGFLOW_SUPERUSER_PASSWORD=SUPERUSER_PASSWORD \
      langflowai/langflow:latest
    ```

    官方 Docker 镜像默认设置 `LANGFLOW_AUTO_LOGIN=false`。

    请将 `SUPERUSER_PASSWORD` 替换为 Langflow 超级管理员的高强度密码。

    更多信息请参见 [Docker 镜像默认安全配置](/deployment-docker#docker-image-security-defaults)。

3. 访问 `http://localhost:7860/` 进入 Langflow。

4. 按照[快速入门](/get-started-quickstart)创建你的第一个 flow。

## 安装并运行 Langflow OSS Python 包 {#install-and-run-the-langflow-oss-python-package}

1. 确认满足以下依赖和基础设施要求:

    - [Python](https://www.python.org/downloads/release/python-3100/) 3.10 至 3.14
    - [uv](https://docs.astral.sh/uv/getting-started/installation/)
    - 足够的基础设施:
       - 最低配置:双核 CPU 和 2 GB 内存
       - 推荐配置:多核 CPU 和至少 4 GB 内存
    - 浏览器:
       - 推荐使用 Google Chrome,但非必需

2. 使用 [uv](https://docs.astral.sh/uv/pip/environments) 创建虚拟环境。

    <details>
    <summary>需要虚拟环境方面的帮助?</summary>

    虚拟环境能确保 Langflow 安装在一个隔离、干净的环境中。创建新虚拟环境的步骤如下。

        <Tabs>
        <TabItem value="linux-macos" label="Linux 或 macOS" default>

        1. 进入你希望创建虚拟环境的目录,然后用 `uv` 创建:

            ```shell
            uv venv VENV_NAME
            ```

            将 `VENV_NAME` 替换为你的虚拟环境名称。

        2. 激活虚拟环境:

            ```shell
            source VENV_NAME/bin/activate
            ```

            Shell 提示符会变化,表明你当前正工作在虚拟环境中:

            ```text
            (VENV_NAME) ➜  langflow git:(main) ✗
            ```

        3. 输入 `deactivate` 即可停用虚拟环境,回到常规 shell。

            虚拟环境激活时会临时修改你的 `PATH` 变量,优先使用虚拟环境内安装的包。
            为避免与其他项目冲突,建议用完后停用虚拟环境。

            输入 `rm -rf VENV_NAME` 即可删除虚拟环境。
            这会彻底删除虚拟环境目录及其中的所有内容。

        </TabItem>
        <TabItem value="Windows" label="Windows">

        1. 进入你希望创建虚拟环境的目录,然后用 `uv` 创建。

            ```shell
            uv venv VENV_NAME
            ```

            将 `VENV_NAME` 替换为你的虚拟环境名称。

        2. 激活虚拟环境:

            ```shell
            VENV_NAME\Scripts\activate
            ```

            Shell 提示符会变化,表明你当前正工作在虚拟环境中:

            ```text
            (VENV_NAME) PS C:/users/username/langflow-dir>
            ```

        3. 输入 `deactivate` 即可停用虚拟环境,回到常规 shell。

            虚拟环境激活时会临时修改你的 `PATH` 变量,优先使用虚拟环境内安装的包。
            为避免与其他项目冲突,建议用完后停用虚拟环境。

            输入 `Remove-Item VENV_NAME` 即可删除虚拟环境。
            这会彻底删除虚拟环境目录及其中的所有内容。

        </TabItem>
        </Tabs>

    </details>

3. 在虚拟环境中安装 Langflow:

    ```bash
    uv pip install langflow
    ```

    这会安装可运行的 Langflow 应用及其精选的提供商扩展。如果需要同样的 UI 和 API 但不要提供商扩展,可以改为安装 `langflow-base`:

    ```bash
    uv pip install langflow-base
    ```

    两个包都使用 `langflow` 命令。在 Langflow 1.12 中,
    `langflow-base` 不再提供名为 `langflow-base` 的可执行文件。

4. 启动 Langflow:

    ```bash
    uv run langflow run
    ```

    Langflow 启动可能需要几分钟。

5. 访问 Langflow 默认地址 `http://127.0.0.1:7860`,确认本地 Langflow 实例已在运行。

6. 按照[快速入门](/get-started-quickstart)创建你的第一个 flow。

### 管理 Langflow OSS 版本

要将 Langflow 升级到最新版本,运行 `uv pip install langflow -U`。
不过,Langflow 团队建议在升级前先备份现有安装。
更多信息请参见[升级前的准备](/release-notes#prepare-to-upgrade)。

要安装特定版本的 Langflow 包,在命令中带上目标版本号,例如 `uv pip install langflow==1.4.22`。

要重装 Langflow 及其全部依赖,运行 `uv pip install langflow --force-reinstall`。

:::note Langflow 1.12 包迁移
新的可运行包 `langflow-base` 从 `1.12.0` 版本开始,并与 `langflow`
保持版本同步。形如 `langflow-base~=0.12` 的依赖仍指向旧包线,
不会选中 1.12 应用。
:::
