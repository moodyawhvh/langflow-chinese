通过加载一个模板 flow、运行它,然后通过 `/run` API 端点对外提供服务,即可快速上手 Langflow。

## 前置条件

- [安装并启动 Langflow](/get-started-installation)
- 创建一个 [OpenAI API key](https://platform.openai.com/api-keys)
- 创建一个 [Langflow API key](/api-keys-and-authentication)

    <details>
    <summary>创建 Langflow API key</summary>

    Langflow API key 是一个用户专属的令牌,可在 Langflow 中使用。

    创建 Langflow API key 的步骤:

    1. 在 Langflow 中点击你的用户头像,选择 **Settings**。
    2. 点击 **Langflow API Keys**,然后点击 <Icon name="Plus" aria-hidden="true"/> **Add New**。
    3. 为 key 命名,然后点击 **Create API Key**。
    4. 复制 API key 并妥善保存。
    5. 要在请求中使用 Langflow API key,请在终端设置 `LANGFLOW_API_KEY` 环境变量,并在请求中附带 `x-api-key` 请求头或查询参数。
    例如:

        ```bash
        # Set variable
        export LANGFLOW_API_KEY="sk..."

        # Send request
        curl --request POST \
        --url "http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID" \
        --header "Content-Type: application/json" \
        --header "x-api-key: $LANGFLOW_API_KEY" \
        --data '{
          "output_type": "chat",
          "input_type": "chat",
          "input_value": "Hello"
        }'
        ```

    </details>

:::tip
如果注册时遇到报错 "An API key must be passed as query or header",请参见[故障排查](/troubleshoot#an-api-key-must-be-passed-as-query-or-header)。
:::

## 运行 Simple Agent 模板 flow

1. 在 Langflow 中点击 **New Flow**,然后选择 **Simple Agent** 模板。

![Simple Agent 模板](/img/quickstart-simple-agent-flow.png)

**Simple Agent** 模板由一个 [**Agent** 组件](/agents)连接到 [**Chat Input** 和 **Chat Output** 组件](/chat-input-and-output)、一个 [**Calculator** 组件](/calculator)和一个 [**URL** 组件](/url)组成。运行此 flow 时,你通过 **Chat Input** 组件向代理提交查询,代理使用 **Calculator** 和 **URL** 工具生成响应,然后通过 **Chat Output** 组件返回结果。

许多组件都可以作为代理的工具,包括[模型上下文协议(MCP)服务器](/mcp-server)。代理会根据给定查询的上下文决定调用哪些工具。

2. 在 **Agent** 组件中点击 **Setup Provider**,选择你的语言模型提供商。
   <PartialGlobalModelProviders />
3. 在 **Agent** 组件中,从 **Language Model** 下拉框选择你配置的模型。

    <details>
    <summary>访问更多模型和提供商</summary>

    有两种方式可以访问更多模型和提供商:

    * 编辑 Langflow 全局的 <Icon name="BrainCog" aria-hidden="true" /> **Models** 配置。这些提供商和模型属于 Langflow 核心功能。使用 **Ollama** 提供商可以连接本地或远程 Ollama 实例上托管的任意模型。
    * 将任意[附加语言模型组件](/components-models#additional-language-models)连接到 **Agent** 组件的 **Language Model** 端口。

    </details>

4. 点击 <Icon name="Play" aria-hidden="true"/> **Playground** 运行 flow。

5. 要测试 **Calculator** 工具,向代理提一个简单的数学问题,例如 `I want to add 4 and 4.`
   为了帮助你测试和评估 flow,**Playground** 会展示代理的分析提示、选择工具、再用工具生成响应的完整推理过程。
   在这个例子中,数学问题会让代理选择 **Calculator** 工具,并执行类似 `evaluate_expression` 的动作。

![Playground 中的代理工具](/img/quickstart-simple-agent-playground.png)

6. 要测试 **URL** 工具,向代理询问时事新闻。
   对于这类请求,代理会选择 **URL** 工具的 `fetch_content` 动作,然后返回当前新闻标题的摘要。

7. 测试完成后,点击 <Icon name="X" aria-hidden="true"/> **Close**。

:::tip 下一步
你已经运行了第一个 flow,接下来可以:

- 编辑你的 **Simple Agent** flow,为其挂接不同的工具或添加更多[组件](/concepts-components)。
- 从零开始[构建自己的 flow](/concepts-flows),或者改造其他模板 flow。
- 将 flow 集成到你的应用中,参见[从外部应用运行你的 flow](#run-your-flows-from-external-applications)。
:::

## 从外部应用运行你的 flow

Langflow 是一个 IDE,同时也是一个运行时,你可以通过 [Langflow API](/api-reference-api-examples) 用 Python、JavaScript 或 HTTP 调用它。

本地启动 Langflow 后,你可以向本地 Langflow 服务器发送请求。
对于生产应用,你需要[部署一个稳定的 Langflow 实例](/deployment-overview)来处理 API 调用。

例如,你可以使用 `/run` 端点运行 flow 并获取结果。

Langflow 提供了代码片段,帮助你快速上手 Langflow API。

1. 编辑 flow 时,点击 **Share**,然后点击 **API access**。

    API access 面板中的默认代码构建了一个包含 Langflow 服务器 `url`、`headers` 和请求数据 `payload` 的请求。
    代码片段会自动带上该 flow 的 `LANGFLOW_SERVER_ADDRESS` 和 `FLOW_ID` 值,并包含一段脚本:如果你已在终端会话中设置了 `LANGFLOW_API_KEY` 环境变量,脚本会自动附带该 key。
    如果你要把代码用于其他服务器或 flow,请替换这些值。
    Langflow 服务器默认地址为 `http://localhost:7860`。

    <Tabs>
    <TabItem value="Python" label="Python" default>

    ```python
    import requests

    url = "http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID"  # The complete API endpoint URL for this flow

    # Request payload configuration
    payload = {
        "output_type": "chat",
        "input_type": "chat",
        "input_value": "hello world!"
    }

    # Request headers
    headers = {
        "Content-Type": "application/json",
        "x-api-key": "$LANGFLOW_API_KEY"
    }

    try:
        # Send API request
        response = requests.request("POST", url, json=payload, headers=headers)
        response.raise_for_status()  # Raise exception for bad status codes

        # Print response
        print(response.text)

    except requests.exceptions.RequestException as e:
        print(f"Error making API request: {e}")
    except ValueError as e:
        print(f"Error parsing response: {e}")
    ```

    </TabItem>
    <TabItem value="JavaScript" label="JavaScript">

    ```js
    const payload = {
        "output_type": "chat",
        "input_type": "chat",
        "input_value": "hello world!",
        "session_id": "user_1"
    };

    const options = {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'x-api-key': 'LANGFLOW_API_KEY'
        },
        body: JSON.stringify(payload)
    };

    fetch('http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID', options)
        .then(response => response.json())
        .then(response => console.log(response))
        .catch(err => console.error(err));
    ```

    </TabItem>
    <TabItem value="curl" label="curl">

    ```bash
    curl --request POST \
         --url 'http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID?stream=false' \
         --header 'Content-Type: application/json' \
         --header "x-api-key: LANGFLOW_API_KEY" \
         --data '{
          "output_type": "chat",
          "input_type": "chat",
          "input_value": "hello world!"
          }'

    # A 200 response confirms the call succeeded.
    ```

    </TabItem>
    </Tabs>

2. 复制代码片段,粘贴到脚本文件中并运行,即可发送请求。
   如果用的是 curl 片段,直接在终端运行该命令即可。

请求成功时,响应会包含这次 flow 运行的众多细节,包括会话 ID、输入、输出、组件、耗时等。

在生产应用中,你通常只需要选取响应中的一部分返回给用户、写入日志等。下面的步骤演示如何从 Langflow API 响应中提取数据供应用使用。

### 从响应中提取数据

下面的例子基于 API 面板的示例代码,在终端里实现一个问答聊天,并保存代理上一次的回答。

1. 把你的 **Simple Agent** flow 的 `/run` 代码片段合入以下脚本。
   该脚本在终端运行问答聊天,并保存代理上一次的回答以便对比。

    <Tabs>
    <TabItem value="Python" label="Python" default>

    ```python
    import requests
    import json

    url = "http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID"

    def ask_agent(question):
        payload = {
            "output_type": "chat",
            "input_type": "chat",
            "input_value": question,
        }

        headers = {
        "Content-Type": "application/json",
        "x-api-key": "LANGFLOW_API_KEY"
        }

        try:
            response = requests.post(url, json=payload, headers=headers)
            response.raise_for_status()

            # Get the response message
            data = response.json()
            message = data["outputs"][0]["outputs"][0]["outputs"]["message"]["message"]
            return message

        except Exception as e:
            return f"Error: {str(e)}"

    def extract_message(data):
        try:
            return data["outputs"][0]["outputs"][0]["outputs"]["message"]["message"]
        except (KeyError, IndexError):
            return None

    # Store the previous answer from ask_agent response
    previous_answer = None

    # the terminal chat
    while True:
        # Get user input
        print("\nAsk the agent anything, such as 'What is 15 * 7?' or 'What is the capital of France?')")
        print("Type 'quit' to exit or 'compare' to see the previous answer")
        user_question = input("Your question: ")

        if user_question.lower() == 'quit':
            break
        elif user_question.lower() == 'compare':
            if previous_answer:
                print(f"\nPrevious answer was: {previous_answer}")
            else:
                print("\nNo previous answer to compare with!")
            continue

        # Get and display the answer
        result = ask_agent(user_question)
        print(f"\nAgent's answer: {result}")
        # Store the answer for comparison
        previous_answer = result
    ```

    </TabItem>
    <TabItem value="JavaScript" label="JavaScript">

    ```js
    const readline = require('readline');

    const rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout
    });

    const url = 'http://LANGFLOW_SERVER_ADDRESS/api/v1/run/FLOW_ID';

    // Store the previous answer from askAgent response
    let previousAnswer = null;

    // the agent flow, with question as input_value
    async function askAgent(question) {
        const payload = {
            "output_type": "chat",
            "input_type": "chat",
            "input_value": question
        };

        const options = {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'x-api-key': 'LANGFLOW_API_KEY'
            },
            body: JSON.stringify(payload)
        };

        try {
            const response = await fetch(url, options);
            const data = await response.json();

            // Extract the message from the nested response
            const message = data.outputs[0].outputs[0].outputs.message.message;
            return message;
        } catch (error) {
            return `Error: ${error.message}`;
        }
    }

    // the terminal chat
    async function startChat() {
        console.log("\nAsk the agent anything, such as 'What is 15 * 7?' or 'What is the capital of France?'");
        console.log("Type 'quit' to exit or 'compare' to see the previous answer");

        const askQuestion = () => {
            rl.question('\nYour question: ', async (userQuestion) => {
                if (userQuestion.toLowerCase() === 'quit') {
                    rl.close();
                    return;
                }

                if (userQuestion.toLowerCase() === 'compare') {
                    if (previousAnswer) {
                        console.log(`\nPrevious answer was: ${previousAnswer}`);
                    } else {
                        console.log("\nNo previous answer to compare with!");
                    }
                    askQuestion();
                    return;
                }

                const result = await askAgent(userQuestion);
                console.log(`\nAgent's answer: ${result}`);
                previousAnswer = result;
                askQuestion();
            });
        };

        askQuestion();
    }

    startChat();
    ```

    </TabItem>
    </Tabs>

### 使用 tweaks 对单次 flow 运行应用临时覆盖

你可以在请求中附带 tweaks,临时修改 flow 参数。
tweaks 会附加到 API 请求中,临时改变 flow 内组件的参数。
tweaks 仅在单次运行中覆盖组件设置。
它们不会修改 flow 的底层配置,也不会在多次运行之间持久化。

tweaks 附加在 `/run` 端点的 `payload` 中。
为了方便格式化,建议在复制代码片段前先[暴露想要覆盖的字段](/concepts-publish#input-schema)。

1. 在画布上选中要覆盖参数的组件。
2. 点击 **Parameters**,然后在想要纳入代码片段的字段上点击 **API**。
3. 点击 **Share** > **API access**。
   在字段上启用 **API** 不会永久改变参数值,只是把该字段加进示例代码片段。
4. 例如,要把代理的 LLM 从 OpenAI 切换到 Anthropic,并在请求中附带 Anthropic API key,可以选中 **Agent** 组件,打开 **Parameters**,然后在 **Language Model** 字段上启用 **API**。

Langflow 会根据你暴露的参数更新代码片段中的 `tweaks` 对象,并附带默认值供参考。
在脚本中使用更新后的代码片段,即可带着你的覆盖设置运行 flow。

```json
payload = {
    "output_type": "chat",
    "input_type": "chat",
    "input_value": "hello world!",
    "tweaks": {
        "Agent-ZOknz": {
            "agent_llm": "Anthropic",
            "api_key": "ANTHROPIC_API_KEY",
            "model_name": "claude-opus-4-5-20251101"
        }
    }
}
```
