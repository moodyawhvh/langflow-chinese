你可以通过多种方式与 Langflow 社区互动,并深入了解 Langflow 代码库。

## 加入 Langflow Discord 服务器

加入 [Langflow Discord 服务器](https://discord.gg/EqksyE2EX9)提问交流,展示你的项目。

## 在 X 上关注 Langflow

在 X 上关注 [@langflow_ai](https://twitter.com/langflow_ai),获取 Langflow 的最新动态。

## 在 GitHub 上给 Langflow 点 Star

如果你喜欢 Langflow,可以给 [Langflow GitHub 仓库](https://github.com/langflow-ai/langflow)点个 star。
Star 能帮助其他用户更容易地找到 Langflow,也能让大家快速看出这个项目对别人确实有用。

Langflow 是开源项目,仓库曝光度越高,代码库就越有可能吸引到[贡献者](/contributing-how-to-contribute)。

## Watch GitHub 仓库

你可以 watch [Langflow GitHub 仓库](https://github.com/langflow-ai/langflow),及时收到新版本发布和其他仓库动态的通知。

如果只想接收发布通知,选择 **Releases only**。

如果选择 **Watching**,你会收到新版本通知,以及 issue、讨论和 pull request 的动态(如果你感兴趣的话)。
关于自定义仓库通知的更多信息,请参见 [GitHub 关于仓库订阅的文档](https://docs.github.com/en/account-and-profile/managing-subscriptions-and-notifications-on-github/managing-subscriptions-for-activity-on-github/viewing-your-subscriptions)。

## 通过 GitHub 请求功能增强并获取帮助

你也可以通过 GitHub 仓库提交功能请求并获取 Langflow 帮助。
更多信息请参见[获取帮助与请求功能增强](/contributing-github-issues)。
