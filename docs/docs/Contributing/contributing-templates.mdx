向 Langflow 提交模板时,请遵循以下最佳实践。

模板格式示例请参见 Langflow 仓库中的 [`/starter_projects`](https://github.com/langflow-ai/langflow/tree/main/src/backend/base/langflow/initial_setup/starter_projects)。

## 通过 PR 提交你的模板

按以下步骤提交模板:

1. 在 GitHub 上 Fork [Langflow 仓库](https://github.com/langflow-ai/langflow)。
2. 在你的 fork 中,把 `template.json` 文件加入 `/starter_projects`。
3. 补齐[模板提交必备项](#required-items-for-template-submission)。
4. 从你的 fork 向 Langflow 主仓库发起 Pull Request(PR)。
5. 在 PR 中附上模板的截图。

Langflow 团队会评审你的 PR、给出反馈,批准后合并该模板。

## 模板提交必备项

提交模板时,请包含以下内容并遵循以下准则。

### 名称

模板名称必须简洁,不超过三个单词。
仅首字母大写。
例如:**Blog Writer** 或 **Travel Planning Agent**。

### 描述

提供简明、信息充分的描述,显示在可视化编辑器中,帮助用户理解模板的用途和适用场景。
例如:

```json
   "description": "Auto-generate a customized blog post from instructions and referenced articles.",
```

### 图标

使用 [Lucide](https://lucide.dev/icons/) 图标库中的图标。

### Flow

只使用 <Icon name="Component" aria-hidden="true" /> **Core components** 和 <Icon name="Blocks" aria-hidden="true" /> **Bundles**。
不要使用不属于 Langflow 代码库的自定义组件。

在 <Icon name="StickyNote" aria-hidden="true"/> **Note** 中写明简要 README、快速上手或其他关键信息。Note 支持 Markdown 语法。
例如:

```text
# Financial Assistant Agents

The Financial Assistant Agent retrieves web content and writes reports about finance.

## Prerequisites

* [OpenAI API key](https://platform.openai.com/api-keys)
* [Tavily AI Search key](https://docs.tavily.com/welcome)
* [Sambanova API key](https://sambanova.ai/)

## Quickstart

1. In both **Agent** components, add your OpenAI API key.
2. In the **Model Provider** field, select **Sambanova**, and select a model.
3. In the **Sambanova** component, add your **Sambanova API key**.
4. In the **Tavily Search** component, add your **Tavily API key**.
5. Click the **Playground** and ask `Why did Nvidia stock drop in January?`
```

### 格式

以 JSON 格式提交模板。

### 标签

为模板指定以下类别之一:

- Assistants(助手)
- Classification(分类)
- Coding(编程)
- Content Generation(内容生成)
- Q&A(问答)
- Prompting(提示工程)
- RAG
- Agents(代理)

更多信息参见 Langflow 仓库的[模板类别](https://github.com/langflow-ai/langflow/blob/main/src/frontend/src/modals/templatesModal/index.tsx#L27-L57)。
